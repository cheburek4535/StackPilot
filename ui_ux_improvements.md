# StackPilot UI/UX Audit & Modernization Plan

Этот документ описывает зоны роста и конкретные шаги по доведению UI/UX приложения до премиального уровня (в стиле macOS, GitHub, JetBrains Fleet, Linear), с использованием эффекта матового стекла (Glassmorphism) и современных микро-интеракций.

## 1. True Glassmorphism (Vibrancy / Mica)
Сейчас в приложении (в `theme.css`) используется имитация стекла через полупрозрачные цвета фона (`--sp-solid-chrome` и `--sp-glass-bg`) без реального размытия подложки. 

**Как сделать как в macOS / Windows 11:**
1. В `tauri.conf.json` включить прозрачность окна:
   ```json
   "windows": [
     {
       "transparent": true,
       "decorations": false
     }
   ]
   ```
2. Использовать Tauri плагин `window-vibrancy` (или нативные API Tauri 2) для включения акрилового эффекта ОС (Mica для Windows, NSVisualEffectView для macOS).
3. Обновить `theme.css`:
   - Убрать глухие черные фоны (`#050507`). Использовать полупрозрачные, например `rgba(0, 0, 0, 0.4)`.
   - Заменить `border-right: 1px solid var(--sp-border)` на внутренние тени (inset box-shadow), чтобы свет преломлялся на гранях панелей: `box-shadow: inset -1px 0 0 rgba(255, 255, 255, 0.05)`.

## 2. Типографика и Контраст (уровень Linear / GitHub)
В приложении заявлен `Inter` и `SF Pro Display`, но не используются продвинутые настройки шрифтов, которые делают UI «дорогим».

**Улучшения:**
1. **Letter-spacing:** Для заголовков (h1, h2) используйте отрицательный трекинг: `letter-spacing: -0.02em;` или `-0.015em`.
2. **Font Features:** Включите лигатуры и выравнивание цифр для таймеров (например, в DevLauncher): 
   ```css
   font-variant-numeric: tabular-nums;
   font-feature-settings: "cv05", "cv08", "ss01";
   ```
3. Уменьшите контрастность неактивного текста. Сейчас `--sp-text-2: #a3adbf` немного ярковат для второстепенного текста на фоне стекла. Сделайте его более приглушенным, позволив стеклу просвечивать через текст.

## 3. Микро-анимации и Пружинная физика (Spring Physics)
Сейчас кнопки (`Button.svelte`) используют линейные `transform: scale(0.98)` с `transition: ... 0.1s ease`.

**Улучшения:**
1. Замените стандартные `ease` кривые на пружинные (как в iOS):
   ```css
   transition: transform 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.1);
   ```
2. Использовать встроенные в Svelte 5 функции `spring` для сложных переходов (появление модалок, раскрытие секций в мастере создания проектов). Модальные окна должны появляться с небольшим увеличением масштаба (с 0.95 до 1.0).

## 4. Грани и тени (Стеклянные блики)
В `theme.css` есть переменные типа `--sp-gloss-top`, но они слишком резкие.
Для достижения эффекта "дорогого стекла":
1. У панелей (Карточки, Сайдбар) должна быть комбинированная тень: внешняя черная для объема и внутренняя белая (очень тонкая, 0.5px) для имитации фаски стекла.
   ```css
   box-shadow: 
     0 8px 32px rgba(0, 0, 0, 0.2), 
     inset 0 1px 1px rgba(255, 255, 255, 0.1),
     inset 0 0 0 1px rgba(255, 255, 255, 0.05);
   ```
2. Размытие у карточек (если они плавают над контентом) должно быть `backdrop-filter: blur(24px) saturate(150%)`.

## 5. UI/UX Layout Masters
1. В `AppShell.svelte` сайдбар жестко отрезан линией (`border-right`). В современных UI (macOS) сайдбар часто полностью прозрачен и сливается с фоном ОС, а основной контент лежит в "листе" (content area) с небольшим скруглением (`border-radius: 10px`) и своей тенью поверх сайдбара.
2. Мастер создания (`create/+page.svelte`): переработать 6 шагов из линейного скролла в красивые изолированные карточки с горизонтальным свайпом (как в установщиках macOS) или в формате "Focus Mode", где ничего не отвлекает от текущего вопроса.
